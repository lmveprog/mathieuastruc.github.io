# mathieu astruc — portfolio

Single-page portfolio built with Next.js. ASCII portrait, decrypt-on-hover typography,
light/dark toggle, and a short list of what I'm building.

**Live → [mathieuastruc.com](https://mathieuastruc.com)**

## Dev

```
npm install
npm run dev
```

`/matheus` is a private dashboard behind basic auth — set `MATHEUS_PW` (see `.env.local.example`).
